# PI-2018-Project

Reutilizaçao do projecto FireFight Simulator desenvolvido em POO1718.

A idéia passa por acrescentar aleatoriedade ao simulador: criação do mapa, modulação de fatores que alterem a propagação do fogo, etc.

Possibilidade de adicionar um objectivo para tornar o simulador mais interessante (p.e. evitar a propagação do fogo a determinada área)
